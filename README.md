# 부산 관광 수요와 숙박·소비 특성 분석

한국관광 데이터랩에서 수집한 자료를 활용하여 부산의 월별 방문 규모, 관광지별 입장객 집중도, 숙박자 비율과 관광소비의 관계를 탐색한 개인 데이터 분석 프로젝트입니다.

데이터 수집·정리부터 전처리, 시각화, 결과 해석, 개선 방향과 KPI 후보 제안까지 진행했습니다.

## 분석 질문

1. 부산의 방문 규모는 월별로 어떻게 변하며, 반복되는 계절적 특징이 있는가?
2. 수집된 관광지 9곳 중 입장객은 어느 시설에 집중되는가?
3. 방문객이 많은 달에 숙박자 비율도 높게 나타나는가?
4. 방문객이 많은 달에 관광소비액도 많으며, 방문 규모를 고려한 소비 지표가 높은 달은 언제인가?

## 주요 결과

| 분석 항목 | 결과 |
| --- | --- |
| 월별 변화·계절성 | 2024~2025년 월별 평균에서 방문자수는 8월, 순 방문자수는 2월에 가장 높았습니다. 계절별 최고 시기는 연도에 따라 달라 고정된 성수기를 확정하기 어려웠습니다. |
| 관광지 집중도 | 2024~2025년 수집된 관광지 9곳에서 상위 4곳의 입장객수 합계가 전체의 약 79.4%를 차지했습니다. |
| 숙박자 비율 | 숙박자 비율과의 상관계수는 순 방문자수 0.175, 방문자수 0.298로 약한 양의 선형 관계를 보였습니다. |
| 관광소비 | 순 방문자수와 관광소비액의 상관계수는 0.457이었습니다. 총소비액이 가장 높은 달과 방문 규모 대비 소비 지표가 가장 높은 달은 달랐습니다. |

분석 결과를 바탕으로 숙박 연계 콘텐츠와 관광지 간 연계 가능성 등을 검토할 방향으로 제안했습니다. 향후 추적할 KPI 후보로 순 방문자수·관광소비액의 전년 동월 증감률과 숙박자 비율의 전년 동월 대비 변화(%p)를 제시했습니다.

개선안과 KPI는 향후 검토·추적을 위한 제안이며, 실제 사업의 개선 효과나 목표 달성을 평가한 결과는 아닙니다.

## 사용 데이터

- **출처:** 한국관광 데이터랩의 다운로드 CSV
- **대상 지역:** 부산광역시
- **전체 수집 기간:** 2024년 1월~2026년 10월, 34개월
- **수집 방식:** 웹사이트에서 파일 다운로드, API 미사용

| 분석용 데이터 | 구조 | 주요 항목 |
| --- | --- | --- |
| 월별통합표 | 34행 × 4열 | 기준연월, 방문자수, 순 방문자수, 숙박자 비율 |
| 관광소비상세표 | 272행 × 3열 | 기준연월, 업종대분류명, 소비액(천원) |
| 유료관광지점상세표 | 306행 × 6열 | 기준연월, 관광지명, 지역, 입장객수, 순위 |

월별 평균·계절별 비교에는 완결된 2024~2025년 자료를 사용했습니다. 관광지 입장객수의 결측 57건은 모두 2026년에 있어, 관광지 간 비교도 2024~2025년으로 한정했습니다. 숙박·소비 관계 분석에는 전체 34개월을 사용했습니다.

**원본 및 분석용 CSV 파일은 저장소에 포함하지 않습니다.**

## 재실행 방법

분석 노트북은 아래 세 개의 정리된 CSV를 입력으로 사용합니다. 재실행하려면 데이터를 별도로 준비해야 합니다.

```text
24012610_월별통합표.csv
24012610_관광소비상세표.csv
24012610_유료관광지점상세표.csv
```

1. 위 파일을 Google Drive의 `내 드라이브/tourism` 폴더에 저장합니다.
2. 상단의 Colab 링크에서 노트북을 열고 개인 Drive에 사본을 저장합니다.
3. Google Drive를 연결하고, 데이터 불러오기 셀의 `folder` 경로를 확인합니다.
4. 첫 번째 셀부터 순서대로 전체 실행합니다.

현재 데이터 폴더 경로는 다음과 같습니다.

```python
folder = '/content/drive/MyDrive/tourism'
```

관광소비상세표는 현재 코드에서 `cp949` 인코딩으로 읽습니다. 별도로 준비한 파일의 인코딩이 다르면 해당 설정을 변경해야 합니다.

## 해석의 범위와 한계

- 계절 비교에 사용한 완결연도는 두 해이므로 일반적인 계절성을 단정하지 않습니다.
- 관광지 9곳은 다운로드 자료에 포함된 지점이며, 부산 전체 관광지를 대표하는 표본은 아닙니다.
- 관광지 입장객수는 중복을 제거한 고유 관광객 수가 아닙니다. 원본의 0도 미입력 값일 가능성이 있어 해석에 주의가 필요합니다.
- 숙박자 비율은 실제 예약 전환율이나 체류시간을 의미하지 않습니다.
- 방문 규모 대비 소비액은 서로 다른 집계자료를 나눈 참고 지표이며, 실제 관광객 1인당 평균 지출액이 아닙니다.
- 상관관계는 인과관계를 의미하지 않습니다. 연도·월·휴일·물가 등의 영향을 별도로 통제하거나 통계적 유의성을 검정하지 않았습니다.

시설별 집계 범위 등 세부 한계와 추가 확인 과제는 분석 리포트에 정리했습니다.
